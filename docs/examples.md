# 示例

[**中文**](./examples.md) | [English](./en/examples.md)


本文给出两个示例：一个最小 demo（无 globals），一个包含条件、效果、图片与自动路由的完整示例。

---

## 1. 最小 demo（无 globals）

```
@title 开场
@char 萧影

[雨水模糊了视线。]

萧影:[你来了。]

@next(萧影):[继续] -> 医院
    ()[回头] -> 回头

@title 医院
@char 萧影

[
两人走进医院。
]

@next -> END

@title 回头
@char 萧影

[
萧影转身离开。
]

@next -> END
```

要点：

- 没有 `@globals`，没有任何状态。
- 选择分支直接靠目标模块表达。
- 两个模块都用 `@next -> END` 终止。
- 项目默认入口是第一个模块 `开场`。

---

## 2. 完整示例

```
@globals
@var trust_low false
@var has_key false

@title 相信
@char 萧影
@char 影子

[雨水模糊了视线，萧影在泥泞中奔跑……]

萧影:[你来了。]

影子:[别回头。]

@fig "assets/hospital.png"

@set trust_low true

@next(萧影):(trust_low)[相信他] -> 医院 {
    @set has_key true
}
    ()[沉默] -> 沉默

@title 医院
@char 萧影

[
两人走进医院。
]

@next():(has_key) -> 地下层
    () -> 走廊

@title 地下层
@char 萧影

[
萧影找到了钥匙。
]

@next -> END

@title 走廊
@char 萧影

[
走廊空无一人。
]

@next -> END

@title 沉默
@char 萧影

[
萧影没有说话。
]

@next -> END
```

## 3. 图结构

```
            +--------+
            |  相信  |
            +--------+
              |    |
     [相信他] |    | [沉默]
              v    v
          +------+ +------+
          | 医院 | | 沉默 |
          +------+ +------+
            |  |
   (has_key) |  | ()
            v  v
      +--------+ +------+
      | 地下层 | | 走廊 |
      +--------+ +------+
            \      /
             \    /
              v  v
             +-----+
             | END |
             +-----+
```

- `相信` 是选择模式：两个选项都有文案，第二个无条件作为兜底。
- `医院` 是自动模式：按顺序检查条件，`has_key` 为真走地下层，否则走走廊。
- `END` 是唯一终点。

---

## 4. 演示走查

### 路径 A：选择"相信他"

1. 进入 `相信`。
2. 显示旁白、对话、图片。
3. 执行 `@set trust_low true`。
4. 出口判定：
   - `(trust_low)[相信他]` 条件为真，显示。
   - `()[沉默]` 无条件，显示。
5. 玩家选择"相信他"。
6. 执行效果 `@set has_key true`。
7. 进入 `医院`。
8. `医院` 自动路由：
   - `(has_key)` 为真 → 进入 `地下层`。
9. `地下层` → `END`。

### 路径 B：选择"沉默"

1. 进入 `相信`。
2. `trust_low` 被设为 `true`。
3. 玩家选择"沉默"。
4. 进入 `沉默`。
5. `沉默` → `END`。

### 路径 C：`has_key` 为假（通过调试面板覆盖）

1. 从 `相信` 选择"相信他"。
2. 如果预览调试面板把 `has_key` 覆盖为 `false`：
3. 进入 `医院` 后，`(has_key)` 不成立，走 `走廊`。
4. `走廊` → `END`。

---

## 5. 单模块演示

- 选择 `相信` 作为起点：可以走完整个示例（因为目标模块都已加载）。
- 选择 `医院` 作为起点：从医院开始，按 `has_key` 的默认值 `false` 走 `走廊`。
- 单模块隔离导出 `相信`：遇到 `-> 医院` / `-> 沉默` 时，演示结束或显示桩。

---

## 6. 这个示例覆盖的语言特性

- `@globals` 与全局布尔变量
- `@title` 模块边界
- `@char` 角色声明
- 旁白块 `[]`
- 对话块 `角色:[]`
- `@fig` 图片插入
- `@set` 内容级状态修改
- 选择模式出口（带角色、条件、文案、兜底）
- 自动模式出口（条件 + 兜底）
- 分支效果块 `{}`
- `@next -> END` 终止
- 无条件分支兜底
