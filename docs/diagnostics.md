# 诊断码与常见错误

[**中文**](./diagnostics.md) | [English](./en/diagnostics.md)

编辑器会在出错位置显示诊断码。本文列出剧情开发者最常遇到的诊断码、含义和修复方式。

---

## 1. 词法与语法

| 码 | 说明 | 常见修复 |
|---|---|---|
| WFT1001 | 无法识别的字符或指令 | 检查行首是否为支持的 `@` 指令，正文是否写在 `[]` 中 |
| WFT1002 | 正文块未闭合 | 补上结束的 `]` |
| WFT1003 | 指令格式错误 | 检查指令参数，例如 `@var 信任 false` |
| WFT1004 | 出口分支格式错误 | 检查 `(条件)[文案] -> 目标` 的写法 |
| WFT1005 | 模块 ID 包含非法字符 `{` 或 `}` | 从 `@module` 中移除 `{` / `}` |
| WFT1006 | `{}` 引用未闭合 | 在同一行补上 `}` |

## 2. 声明与模块

| 码 | 说明 | 常见修复 |
|---|---|---|
| WFT2001 | 符号声明位置错误 | 把 `@vars` / `@chars` / `@items` / `@scenes` 放在模块之前 |
| WFT2004 | 全局变量重复声明 | 删除重复的 `@var` |
| WFT2005 | 模块 ID 重复 | 修改重复的 `@module` |
| WFT2006 | 模块头指令出现在内容之后 | 把 `@scene` 移到正文之前 |
| WFT2007 | `@title` / `@module` / `@project` / `@chapter` / `@doc` 为空 | 补上标题、模块 ID 或名称 |
| WFT2008 | 对话或出口引用了未声明角色 | 在 `.weft` 顶部 `@chars` 中添加 `@char` |
| WFT2009 | 角色重复声明 | 删除重复的 `@char` |
| WFT2010 | 道具重复声明 | 删除重复的 `@item` |
| WFT2011 | 跨类型符号重名 | 给变量/角色/道具/场景换一个唯一名字 |
| WFT2012 | `.wstory` 中出现 `@set` | 删除；变量初始值写在 `.weft` 的 `@var` |
| WFT2013 | 正文中出现 `@set` | 变量修改只写在出口分支效果 `{ @set ... }` |
| WFT2014 | `{名字}` 引用了未声明角色或道具 | 在 `.weft` 顶部声明，或修正名字 |
| WFT2015 | 场景重复声明 | 删除重复的 `@scene` |
| WFT2016 | 场景名不合法 | 使用合法标识符，例如 `医院` |
| WFT2017 | `.weft` 缺少章节标题 | 在文件第一行写 `@title 章节名` |
| WFT2018 | 一个文件出现多个章节标题 | 一个 `.weft` 只能有一个 `@title` |
| WFT2019 | 章节标题重复 | 给每个章节文件一个唯一标题 |

## 3. 内容与出口

| 码 | 说明 | 常见修复 |
|---|---|---|
| WFT3001 | 模块缺少出口块 | 在模块末尾添加 `@next -> END` 或其他出口 |
| WFT3002 | 出口缺少兜底 | 添加一条无条件分支，或把某条写成 `()` |
| WFT3003 | 混用选择/自动模式 | 选择模式全带 `[文案]`，自动模式全不带 |
| WFT3004 | 文案与模式不匹配 | 选择模式补 `[文案]`；自动模式删除 `[文案]` |
| WFT3005 | 出口块之后仍有内容 | 把内容移到 `@next` 之前 |
| WFT3006 | 条件引用了未声明变量 | 在 `.weft` 顶部 `@vars` 中添加 `@var` |
| WFT3007 | `@set` 引用了未声明变量 | 在 `.weft` 顶部 `@vars` 中添加 `@var` |
| WFT3008 | 布尔表达式语法错误 | 检查 `not` / `and` / `or` 和括号 |
| WFT3009 | 效果块出现非 `@set` 语句 | 效果块只写 `@set` |
| WFT3010 | 同一效果块重复赋值 | 后者会覆盖前者；建议删除重复项 |

## 4. 项目与图

| 码 | 说明 | 常见修复 |
|---|---|---|
| WFT4001 | 目标模块未找到 | 创建目标模块，或修正目标名 |
| WFT4002 | 非法定义或使用 `END` | 不要定义 `@module END`；终止用 `@next -> END` |
| WFT4004 | 模块从入口不可达 | 检查是否有出口指向它 |
| WFT4005 | 存在无法到达 `END` 的路径 | 检查死路和兜底 |
| WFT4007 | 图片资源不存在 | 修正 `@fig` 路径或导入资源 |

---

## 5. 单模块演示

- 外部目标缺失时，演示结束或显示桩，不阻塞。
- 外部变量缺失仍是错误，需要在 `.weft` 中声明。
- 没有变量声明时，变量表为空；不使用变量的模块不受影响。
