# Weftline 语言文档

**状态：v0 草案，供审阅**

Weftline 是一个面向游戏剧本的文本格式与工具。它追求三件事：

1. 写起来像剧本，而不是像程序。
2. 剧情结构可以直接映射为图。
3. 能一键导出可在浏览器中演示的 HTML。

---

## 定位

Weftline 是**剧情 demo / 叙事演示工具**，不是游戏引擎，也不是商业剧情生产管线。

它只对一类工作负责：

- 快速写出可玩的剧情 demo；
- 让剧情结构可视化；
- 导出一个能直接分享、在浏览器里演示的 HTML。

评价标准：

- 从空白到第一个可玩 demo 的时间；
- 图是否清楚反映剧情结构；
- 导出物是否零安装、可直接发给别人；
- 修改剧情后重新演示是否足够快。

以下**不是**它的目标，应由下游引擎或专门工具承担：

- 视觉小说生产：立绘、表情、BGM、存档、回想、本地化、语音；
- RPG 任务、数值、背包系统；
- 游戏引擎内的实时触发、过场、QTE；
- 大型项目的制作管线与多人协作流程。

## 设计原则

- **散文优先**：正文放在 `[]` 中，块内是纯文本，不解析关键字。
- **模块是图节点**：一个模块是一段线性剧情，止于出口。
- **出口是分支接口**：`@next` 声明模块的所有出口，选择与条件都只在这里。
- **状态是可选的**：没有 `@globals` 也能写、能演示、能导出。
- **关键字统一 `@` 前缀**：只有 `@` 开头的才是指令。
- **没有多级条件**：扁平出口块 + 布尔表达式 + 拆模块。
- **单一游标运行时**：没有并发、没有调度器。

---

## 最小示例

```
@title 开场
@char 萧影

[
雨水模糊了视线。
]

萧影:[你来了。]

@next -> END
```

没有 globals、没有分支，也可以完整演示。

## 待审阅的关键约定

以下点建议在审阅时重点确认：

1. **模式判定**：`@next(角色):` 有角色 = 选择模式；无角色 = 自动模式。
2. **模块 ID**：直接使用 `@title` 文本，暂不引入独立 `@id`。
3. **入口**：语言没有入口声明；项目默认从第一个模块开始，单模块演示以该模块为起点。
4. **章节**：v0 不做，未来可能以 `@chapter` 标签形式加入。
5. **图片**：v0 支持 `@fig "path"`，导出时内嵌。
