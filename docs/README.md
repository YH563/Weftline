# Weftline 剧本语言文档

[**中文**](./README.md) | [English](./en/README.md)

Weftline 是一个面向游戏剧本的文本格式与工具。它追求三件事：

1. 写起来像剧本，而不是像程序。
2. 剧情结构可以直接映射为图。
3. 能一键导出可在浏览器里演示的 HTML。

当前阶段：语言核心与桌面编辑器可用，主界面已接入单文件语法诊断、项目语义分析、诊断合并、实时剧情图、悬停、补全、布局侧车、筛选与路径高亮；HTML 导出后续在 C++ 侧实现。

---

## 定位

Weftline 是**剧情 demo / 叙事演示工具**，不是游戏引擎，也不是商业剧情生产管线。

它负责：

- 快速写出可玩的剧情 demo；
- 把剧情结构可视化为图；
- 记录和演示剧情走向；
- 导出零安装、可在浏览器中演示的 HTML。

非目标：立绘、音频、存档、本地化、语音、RPG 数值/背包、引擎内实时逻辑、大型协作管线。

---

## 文件类型

| 后缀 | 角色 |
|---|---|
| `.weft` | 模块脚本：顶部符号声明区（分组可选） + 模块 |
| `.wstory` | 项目总览：项目信息 + 从 `.weft` 生成的声明 + 手写描述 |

- `.weft` 是符号声明的唯一来源。
- `.wstory` 不是声明入口；声明由工具生成，描述由作者手写并保留。
- 同一扁平文件夹下所有 `.weft` 属于同一个故事。

---

## 设计原则

- **散文优先**：正文放在 `[]` 中，块内以纯文本为主。
- **模块是图节点**：一个模块是一段线性剧情，止于出口。
- **出口是分支接口**：`@next` 声明模块的所有出口。
- **声明集中在 `.weft` 顶部**：变量、角色、道具、场景按分组声明。
- **正文引用显式**：正文中的角色/道具用 `{名字}` 标记。
- **状态可选**：没有变量也能写、能演示、能导出。
- **缩进仅显示**：4 空格一级，解析忽略缩进。
- **没有多级条件**：扁平出口块 + 布尔表达式 + 拆模块。

## 最小示例

`.weft`：

```text
@title 第一章 街道

@char 萧影

@scene 街道

@module 开场
    @scene 街道
    [雨水模糊了视线，{萧影}站在街口。]
    萧影:[你来了。]
@next -> END
```

`.wstory`：

```text
@project 雨夜
    @summary [一个关于信任的故事。]

    @chapters
        @chapter 第一章 街道 [雨夜的开端。]

    @chars
        @char 萧影 [主角。]

    @scenes
        @scene 街道 [雨夜的街道。]
```

## 关键约定

1. **正文引用**：`{}` 只引用角色/道具，不引用变量。
2. **章节**：`.weft` 文件第一行的 `@title` 是章节标题；章节是分组，不是图节点。
3. **模块 ID**：`@module` 直接作为模块 ID，项目内全局唯一。
4. **入口**：语言没有入口声明；项目默认从第一个文件的第一个模块开始。
5. **场景**：场景是模块上的可选标签，不是图节点。
6. **变量**：只有布尔；声明必须带初始值；运行期修改只在分支效果。
7. **图片**：v0 支持 `@fig "path"`；HTML 导出接入后内嵌。
