# Weftline 语言规格

[**中文**](./language-spec.md) | [English](./en/language-spec.md)

本文定义 v0 的语义。语法细节见 [grammar.md](./grammar.md)。

---

## 1. 总览

Weftline 把剧本组织为**模块**：

- 一个模块是一段**线性剧情**。
- 模块的结尾是**出口块**，声明它通向哪些模块。
- 模块之间通过出口连接，形成剧情图。
- `END` 是唯一的终止模块。
- 全局状态是可选的布尔变量。

图模型：

```text
Module = 节点
Exit   = 边
END    = 唯一汇点
```

## 2. 项目与文件

### 2.1 项目

一个扁平文件夹就是一个故事：

```text
my-story/
  project.wstory     项目总览：项目信息 + 生成的声明 + 手写描述
  chapter1.weft      章节文件：章节标题 + 顶部声明区 + 模块
  chapter2.weft
  assets/            图片资源
  .weftline/         索引缓存，建议 gitignore
```

- 一个 `.weft` 文件就是一个章节。
- 同一文件夹下所有 `.weft` 自动视为同一个故事。
- 不支持子目录、跨文件夹 import。
- `.weft` 是符号声明的唯一来源。
- `.wstory` 是生成的项目总览；声明由工具生成，描述由作者手写并保留。

### 2.2 `.weft` 章节与顶部声明区

```text
@title 第一章 雨夜

@var 信任 false
@var 有钥匙 false

@char 萧影
@char 影子

@item 医院钥匙

@scene 医院

@module 序
    @scene 街道
    [雨夜，{萧影}走向医院。]
    @scene 医院
    [两人走进医院。]
@next -> 相信

@module 相信
    @scene 医院
    [雨水模糊了视线。]
@next -> END
```

规则：

- 文件第一行必须是 `@title`，一个文件一个章节标题。
- 符号声明在章节标题之后、第一个 `@module` 之前。
- 声明可直接写 `@var` / `@char` / `@item` / `@scene`。
- `@vars` / `@chars` / `@items` / `@scenes` 分组头可选，仅用于视觉分区；平铺和分组可以混用。
- 第一个 `@module` 之前的 `@scene` 是场景声明；`@module` 之后的 `@scene` 是模块内场景标记。
- 变量必须带初始值；`@var 信任` 缺值报错。
- 声明区不写描述；描述写在 `.wstory`。
- 符号名项目内唯一，跨类型也不能重名。
- 缺失符号只报错，工具不自动补声明。

### 2.3 `.wstory` 项目总览

```text
@project 雨夜
    @summary [一个关于信任的故事。]

    @chapters
        @chapter 第一章 雨夜 [开篇。]

    @docs
        @doc 世界规则 [医院在雨夜不关门。]

    @chars
        @char 萧影 [主角。]
        @char 影子 [萧影的旧识。]

    @items
        @item 医院钥匙 [医院地下室的钥匙。]

    @scenes
        @scene 医院 [雨夜里的医院。]

    @vars
        @var 信任 false [萧影是否信任影子。]
        @var 有钥匙 false [是否拿到了医院钥匙。]
```

规则：

- `@project` 顶层；分组缩进一级；条目再缩进一级（仅显示）。
- `@summary` 单行。
- `@chapters` 分组列出章节，章节标题从 `.weft` 的 `@title` 生成，描述手写并保留。
- 声明（名字、变量初始值）从 `.weft` 生成。
- 描述由作者手写，生成时保留。
- `.wstory` 不允许 `@set`，也不允许模块。
- 手改声明会被下次生成覆盖；描述不会。

## 3. 符号

### 3.1 角色、道具与场景

- 角色用于对话说话人和 `@next(角色)`。
- 道具是元数据，正文可用 `{道具名}` 引用。
- 场景是正文流中的切换标记，不产生图节点。
- 一个模块可以包含多个 `@scene`，场景切换不结束模块。
- 场景只作用于它之后的内容，直到下一个 `@scene`；同一个场景可以跨多个模块。

### 3.2 变量

- 只有布尔类型。
- 声明必须带初始值。
- 运行期修改只发生在出口分支效果。
- 正文不支持 `@set`。
- 没有入口覆盖。

| 层次 | 位置 | 生效时机 |
|---|---|---|
| 初始值 | `.weft` 顶部 `@var` | 故事开始 |
| 运行期修改 | 出口分支效果 | 分支被选中后 |

## 4. 内容块

内容块按书写顺序线性执行。

### 4.1 旁白

```text
[雨水模糊了视线。]
```

多行时括号贴正文：

```text
[雨水模糊了视线，
他抬起头。]
```

### 4.2 对话

```text
萧影:[你来了。]
```

多行：

```text
萧影:[你来了。
我等了很久。]
```

- 说话人必须是已声明的全局角色。

### 4.3 正文引用

```text
[{萧影}推开门，手里攥着{医院钥匙}。]
```

- `{名字}` 只引用已声明的角色或道具。
- 不引用变量。
- 导出时只显示名字。
- 编辑器可从引用跳转到 `.wstory` 的描述。
- `{{` 和 `}}` 是字面量转义。
- `{}` 不跨行，不支持嵌套。

### 4.4 图片

```text
@fig "assets/hospital.png"
```

- 在当前内容位置插入图片。
- 路径是相对项目资源的字符串，需用双引号包裹。

### 4.5 注释

```text
// 这是注释
```

- 只在结构层生效。
- 正文块内部不解析注释。

## 5. 出口块

### 5.1 完整形式

```text
@next(角色):(条件)[文案] -> 目标 {
    @set name true
}
    (条件)[文案] -> 目标
    ()[文案] -> 目标
```

### 5.2 简写形式

```text
@next -> 目标
@next -> 目标 { @set name true }
```

### 5.3 模式

| 头 | 模式 | 分支要求 |
|---|---|---|
| `@next(角色):` | 选择模式 | 每个分支必须有非空 `[文案]` |
| `@next():` | 自动模式 | 分支不得有 `[文案]` |
| `@next -> 目标` | 自动模式（单分支） | 无文案、无条件 |

### 5.4 选择模式

- 条件为真的分支全部显示给玩家。
- 条件为假的分支不出现。
- 玩家从可见分支中选择一个。
- 必须至少有一条无条件分支作为兜底。

### 5.5 自动模式

- 按书写顺序检查条件，取第一条成立的分支。
- 必须至少有一条无条件分支作为兜底。
- 条件不要求互斥；顺序决定优先级。

### 5.6 条件

```text
(trust_low)
(a and not b)
((a or b) and c)
```

- 变量来自全局变量表。
- 运算符：`and`、`or`、`not`。
- 优先级：`not` > `and` > `or`。
- 没有比较运算、没有算术、没有函数。

### 5.7 分支效果

```text
-> 医院 {
    @set has_key true
    @set trust_low false
}
```

或同行：

```text
-> 医院 { @set has_key true; @set trust_low false }
```

- 效果块内只允许 `@set` 和注释。
- 执行时机：条件判定 → 分支被选中 → 执行 `@set` → 进入目标模块。
- 条件使用执行效果**之前**的状态。
- 同一块内重复赋值同一变量：后写覆盖，并给出警告。

### 5.8 出口约束

- 每个模块必须有出口块。
- 出口块必须是模块的最后一部分。
- 终止模块使用 `@next -> END`。
- 不支持多级条件；复杂逻辑通过布尔表达式、顺序路由或拆分模块表达。

---

## 6. 执行模型

- 单游标：任意时刻只有一个当前模块。
- 内容块按顺序执行。
- 到出口块时：
  - 选择模式：等待玩家选择。
  - 自动模式：按顺序选第一条成立的分支。
- 选中分支后，先执行效果，再进入目标模块。
- 给定路径与选择，执行结果是确定的。

---

## 7. 入口与单模块处理

语言**没有**入口声明。

- 项目默认入口 = 第一个文件的第一个模块。
- 没有入边的其他模块视为候选入口；用于可达性校验和图角标，不改变默认入口。
- 项目顺序 = 文件顺序（章节顺序）+ 文件内模块顺序。
- 工具界面允许从任意模块开始演示。
- 全量导出使用 `.weft` 的变量初始值。
- 单模块导出时，外部目标视为演示结束或桩。

### END

- `END` 是保留模块 ID，由编译器内置。
- 唯一终止点，不能定义、不能有出口。
- 终止模块必须显式指向它：`@next -> END`。

## 8. 图映射

| 文本 | 图 |
|---|---|
| `@title` | 章节分组标签（不是节点） |
| `@module` | 节点（ID = 模块 ID） |
| `@scene` | 正文流中的场景切换标记 |
| 内容块 | 节点内容 |
| `@next` 每一条分支 | 一条出边 |
| `(角色)` | 边属性（块级） |
| `(条件)` | 边条件 |
| `[文案]` | 边标签（选择模式） |
| `{}` 中的 `@set` | 边效果 |
| `END` | 唯一汇点 |

章节不是图节点；折叠视图可以把章节显示成容器，章节之间的边由跨章节模块边派生。

## 9. 非目标与 v0 暂不做

### 9.1 非目标

- 视觉小说生产：立绘、表情、BGM、音效、存档、回想、本地化、语音；
- RPG 任务、数值、背包系统；
- 游戏引擎内的实时触发、过场、QTE；
- 大型项目的制作管线与多人协作流程。

### 9.2 v0 暂不做

- 数值状态与比较运算
- 多级 / 嵌套条件
- 多入口声明
- 事件契约、数据流分析
- 真并发、调度器
- 引擎导出（Unity / Godot）

---

## 10. 审阅关注点

1. 正文 `{}` 只引用角色/道具，不引用变量。
2. `.weft` 是唯一声明来源，`.wstory` 是生成的总览。
3. 变量声明必须带初始值，运行期只在分支效果中修改。
4. 场景只作为正文流标记，不产生图节点，也不切分模块。
5. 章节是文件级分组，不是图节点；模块是唯一图节点。
6. 缩进只影响显示，不参与解析。
