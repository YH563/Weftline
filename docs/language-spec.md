# Weftline 语言规格

本文定义 v0 的语义。语法细节见 [grammar.md](./grammar.md)。

---

## 1. 总览

Weftline 把剧本组织为**模块**：

- 一个模块是一段**线性剧情**。
- 模块的结尾是**出口块**，声明它通向哪些模块。
- 模块之间通过出口连接，形成剧情图。
- `END` 是唯一的终止模块。
- 全局状态是可选的布尔变量，只在需要条件或跨模块记忆时引入。

图模型：

```
Module = 节点
Exit   = 边
END    = 唯一汇点
```

---

## 2. 文件、模块与 globals

### 2.1 文件

- 一个文件可以包含任意多个模块。
- 文件开头到第一个 `@title` 之前，只允许 `@globals` 和注释。

### 2.2 模块

```
@title 相信
@char 萧影
@char 影子

[
正文……
]

@next(萧影):[相信他] -> 医院
    ()[沉默] -> 沉默
```

- `@title` 开始一个模块。
- **模块 ID = `@title` 的文本**，去除首尾空白。
- 模块 ID 在项目内必须唯一。
- 模块 ID 可以包含空格，但不能包含 `{` 或 `}`。
- 出现新的 `@title` 时，上一个模块结束。

### 2.3 globals

- `@globals` 是全项目**唯一**的全局变量声明块。
- 只能出现在：
  - 某个故事文件最顶部、第一个 `@title` 之前；或
  - 一个独立的 globals 文件（按内容识别：包含 `@globals` 且没有 `@title`）。
- `@var` 只能出现在 `@globals` 内。

```
@globals
@var trust_low false
@var has_key false
```

规则：

- 变量只有布尔类型。
- 全项目最多一个 `@globals` 块。
- 同一变量只能声明一次。
- 没有 `@globals` 时，变量表为空；不含状态的模块照常工作。

### 2.4 角色

- `@char` 在模块头部声明本模块使用的角色。
- 角色作用域是**模块内**。
- 对话说话人、`@next(角色)` 中出现的角色，必须在当前模块声明。
- 不同模块可以各自声明同名角色，互不影响。

## 3. 内容块

内容块按书写顺序线性执行。

### 3.1 旁白

```
[
雨水模糊了视线。
]
```

- 块内为纯文本，不解析任何关键字。
- 单行形式：`[雨水模糊了视线。]`

### 3.2 对话

```
萧影:[
你来了。
我等了很久。
]
```

- 单行形式：`萧影:[你来了。]`
- 说话人必须在当前模块 `@char` 中声明。
- 块内仍是纯文本。
- 即使整场只有一个角色，也要求写说话人，便于配音、立绘、本地化和检索。

### 3.3 图片

```
@fig "assets/hospital.png"
```

- 在当前内容位置插入图片。
- 路径是相对项目资源的字符串，需用双引号包裹。
- 支持 PNG、JPEG、WebP、GIF、SVG。
- 图片属于节点内容，不产生图节点。
- v0 导出时内嵌为 base64；后续可切换为 `assets/` 目录。

### 3.4 状态修改

```
@set trust_low true
```

- 修改全局布尔变量。
- 变量必须已在 `@globals` 中声明。
- 按内容顺序立即执行。

### 3.5 注释

```
// 这是注释
```

- 只在结构层生效。
- 正文块内部不解析注释。

---

## 4. 出口块

出口块是模块的**分支接口**，也是模块的结束边界。

### 4.1 完整形式

```
@next(角色):(条件)[文案] -> 目标 {
    @set has_key true
}
    (条件)[文案] -> 目标
    ()[文案] -> 目标
```

### 4.2 简写形式

```
@next -> 目标
```

表示**单一无条件自动分支**，等价于：

```
@next(): -> 目标
```

### 4.3 模式

模式由 `@next(...)` 中是否指定角色决定，同一出口块内不允许混用：

| 头 | 模式 | 分支要求 |
|---|---|---|
| `@next(角色):` | 选择模式 | 每个分支必须有 `[文案]` |
| `@next():` | 自动模式 | 分支不得有 `[文案]` |
| `@next -> 目标` | 自动模式（单分支） | 无文案、无条件 |

### 4.4 选择模式

- 条件为真的分支全部显示给玩家。
- 条件为假的分支不出现，也不可能被选中。
- 玩家从可见分支中选择一个。
- 必须至少有一条无条件分支作为兜底，保证至少一个选项始终可见。

### 4.5 自动模式

- 按书写顺序检查条件，取第一条成立的分支。
- 条件为假的分支被跳过。
- 必须至少有一条无条件分支作为兜底，避免路由落空。
- 条件**不要求互斥**；顺序决定优先级。

### 4.6 条件

条件使用括号包裹的布尔表达式：

```
(trust_low)
(a and not b)
((a or b) and c)
```

- 变量来自全局变量表。
- 运算符：`and`、`or`、`not`。
- 括号用于分组。
- 优先级：`not` > `and` > `or`。
- 条件可以省略；`()` 等价于无条件。
- 没有比较运算、没有算术、没有函数。

### 4.7 分支效果

```
-> 医院 {
    @set has_key true
    @set trust_low false
}
```

或同行：

```
-> 医院 { @set has_key true; @set trust_low false }
```

- 效果块内只允许 `@set` 和注释。
- 执行时机：条件判定 → 分支被选中 → 执行 `@set` → 进入目标模块。
- 条件使用的是执行效果**之前**的状态。
- 同一块内重复赋值同一变量：后写覆盖，并给出警告。

### 4.8 出口约束

- 每个模块**必须**有出口块。
- 出口块必须是模块的最后一部分。
- 出口块之后不能再有正文、对话、`@fig` 或 `@set`。
- 终止模块使用 `@next -> END`。
- 不支持多级条件；复杂逻辑通过布尔表达式、顺序路由或拆分模块表达。

## 5. 状态与执行

### 5.1 状态

- 只有全局布尔变量。
- 单一声明点：`@globals`。
- 无 `@globals` 时状态为空。

### 5.2 执行模型

- 单游标：任意时刻只有一个"当前模块"。
- 内容块按顺序执行。
- 到出口块时：
  - 选择模式：等待玩家选择。
  - 自动模式：按顺序选第一条成立的分支。
- 选中分支后，先执行 `{}` 中的效果，再进入目标模块。
- 后写覆盖先写。
- 给定路径与选择，执行结果是确定的。

### 5.3 可达性

- 每条路径都应能到达 `END`。
- 不可达的模块、无法到达 `END` 的路径、缺失兜底的出口，都属于诊断范围。

## 6. 入口与单模块处理

语言**没有**入口声明。

### 6.1 项目演示

- 默认入口 = 项目中的**第一个模块**。
- 项目顺序 = 文件在项目中的顺序 + 文件内模块的书写顺序；单文件时即文件内顺序。
- 工具界面允许从任意模块开始演示。

### 6.2 单模块处理

| 模式 | 行为 |
|---|---|
| **单模块编译** | 加载 globals（如有）+ 当前模块；未解析的外部目标给警告，不阻塞 |
| **从模块开始演示** | 加载整个项目，以选中模块为起点，可沿出口继续 |
| **单模块导出** | 只导出当前模块；外部出口视为演示结束或桩 |

### 6.3 外部变量

- 所有变量引用都到唯一的 `@globals` 变量表查找。
- 找不到 → 错误，并提供"在 globals 中添加变量"的快速修复。
- 单模块隔离模式同理；没有 globals 时变量表为空。

### 6.4 END

- `END` 是保留模块 ID，由编译器内置。
- 唯一终止点，不能定义、不能有出口。
- 终止模块必须显式指向它：`@next -> END`。

## 7. 图映射

| 文本 | 图 |
|---|---|
| `@title` | 节点（ID = 标题） |
| 内容块 | 节点内容 |
| `@next` 每一条分支 | 一条出边 |
| `(角色)` | 边属性（块级） |
| `(条件)` | 边条件 |
| `[文案]` | 边标签（选择模式） |
| `{}` 中的 `@set` | 边效果 |
| `END` | 唯一汇点 |

入口不是图结构的一部分，而是演示/导出时选择的起点。

## 8. 非目标与 v0 暂不做

### 8.1 非目标（不属于本工具）

这些是商业游戏剧情**生产管线**的能力，应由下游引擎或专门工具承担：

- 视觉小说生产：立绘、表情、BGM、音效、存档、回想、本地化、语音；
- RPG 任务、数值、背包系统；
- 游戏引擎内的实时触发、过场、QTE；
- 大型项目的制作管线与多人协作流程。

Weftline 负责的是**把剧情写成可演示的 demo**，不是把这些能力全部内建。

### 8.2 v0 暂不做（未来可能追加）

- 章节（未来可能以 `@chapter` 标签加入）
- 数值状态与比较运算
- 多级 / 嵌套条件
- 同块多角色、每分支角色
- 多入口声明
- 事件契约、数据流分析
- 真并发、调度器、纵向对齐
- 引擎导出（Unity / Godot）

---

## 9. 审阅关注点

1. 模式判定是否按"有角色 = 选择模式，无角色 = 自动模式"。
2. `@title` 直接作为模块 ID 是否可接受。
3. 终止模块是否统一写 `@next -> END`。
4. 全局变量是否只允许在唯一 `@globals` 块声明。
5. v0 是否确认不做章节，仅保留模块标题。
